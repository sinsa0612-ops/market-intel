# 관측 정렬 규칙 v1 (사전등록, 2026-08-20)

두 관측을 비교할 때 **어느 것이 먼저 알려졌는지**를 정하는 규칙이다. 이 문서는
`transition_rules_v1.md`와 같은 지위로 **동결**한다 — 한 글자도 고치지 않는다.
바꾸려면 `v2`를 새로 등록하고 코드의 규칙 버전을 올린다.

## 왜 얼리나

2026-08-20 실측. 미국채 10년물 금리와 코스피를 **같은 날짜로 묶어** 방향별
분할표를 냈더니:

```
같은 날 묶음   금리↑일 때 코스피 하락 43.9% · 금리↓일 때 47.6%   (차이 3.7%p)
시차 맞춤      금리↑ 다음날 코스피 하락 51.2% · 금리↓ 다음날 40.8% (차이 10.4%p)
```

**결론이 정반대로 뒤집혔다.** 첫 번째는 "금리는 코스피와 무관하다"로 읽히고
두 번째는 "뚜렷하게 관계있다"로 읽힌다. 틀린 쪽이 더 그럴듯해 보였다는 것이
이 문서가 존재하는 이유다 — 정렬은 매번 새로 판단할 것이 아니라 **미리 정해
놓고 코드가 강제**해야 한다.

## R1 — 세션 순서

같은 달력일 `D` 안에서 값이 확정되는 순서:

```
1. KR  — 한국 장 마감 (KST 당일 오후)
2. US  — 미국 장 마감 / 미국 지표 발표 (KST 다음날 새벽)
```

즉 **미국이 항상 늦다.** 순서 번호가 클수록 늦게 확정된다.

## R2 — 정렬

`원인` 관측으로 `결과` 관측을 설명할 때:

- 원인의 세션이 결과의 세션보다 **늦거나 같으면** → 원인은 `D-1`, 결과는 `D`
- 원인의 세션이 결과의 세션보다 **이르면** → 둘 다 `D`

검산. 원인=미국금리(US), 결과=코스피(KR): US가 늦으므로 금리 `D-1` ↔ 코스피 `D`.
원인=코스피(KR), 결과=S&P500(US): KR이 이르므로 둘 다 `D` — 한국 마감은 미국
마감 전에 이미 알려져 있다.

**같은 세션끼리(US↔US, KR↔KR)는 원인이 `D-1`이다.** 같은 시각에 확정된 두 값
사이에서 한쪽을 원인이라 부르려면 최소한 먼저 있어야 한다.

## R3 — 지표 이름

관측의 종류(category)마다 값이 담긴 칸(metric)이 다르다. 다른 칸으로 조회하면
**오류가 아니라 빈 결과**가 나오고, 빈 결과는 "관계 없음"처럼 보인다.

```
price   -> price_close
macro   -> value
```

2026-08-20 실측 사고: 미국채 금리를 `price_close`로 조회해 결과가 통째로 비었고,
그 빈칸이 29일 중 13일을 엉뚱한 갈래로 분류했다(고친 뒤 5일이 재분류됨).
**조회는 반드시 이 표를 거친다. 모르는 subject는 조용히 비우지 말고 예외를 던진다.**

## R4 — 세션 판정

세션은 새로 등록하지 않는다. 원장의 모든 fact가 이미 `country`를 들고 있고
(`US`/`KR`), 그 값을 그대로 R1의 세션으로 쓴다. 한 subject의 관측에 두 나라가
섞여 있으면 정렬을 정할 수 없으므로 예외를 던진다 — 조용히 하나를 고르지 않는다.

## R5 — 이 규칙이 답하지 않는 것

정렬은 **선후**만 정한다. 선후가 맞다고 인과가 되는 것이 아니다. 정렬은 인과
주장의 **필요조건이지 충분조건이 아니다** — 이 규칙을 통과한 표를 두고 "A 때문에
B"라고 쓰는 것은 여전히 금지다(`/market-claim` 규율).
